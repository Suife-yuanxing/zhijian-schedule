# 05 · 审查清单与无障碍

用法：提测/评审时逐条打勾。任一条不过，先修再谈美观。

---

## A. 层级与语义（8 条）

1. [ ] 玻璃只出现在功能层（导航、控件、浮层），内容层使用标准材质或纯色。
2. [ ] 内容层的瞬时交互控件（slider/toggle）仅在操作瞬间呈现玻璃外观。
3. [ ] 没有玻璃叠玻璃；必须叠加时放在同一融合容器/隔离上下文中。
4. [ ] 一屏独立玻璃层 ≤ 3–5 个。
5. [ ] 玻璃元素确实浮在内容之上，滚动时内容从下方穿过。
6. [ ] 滚动容器带滚动边缘效果（边缘模糊 + 渐隐）。
7. [ ] 玻璃不是装饰性贴图：去掉它之后，界面层级会变差（说明它承担了职责）。
8. [ ] 品牌表达放在内容层，而不是靠给玻璃染色来完成。

## B. 变体与选择（7 条）

9. [ ] 有明确的 regular / clear 使用规则，并写进设计说明。
10. [ ] clear 只用于视觉丰富背景（照片、视频）之上。
11. [ ] clear 遇到亮背景时，加了 35% 深色压暗层（或使用自带压暗的媒体控件）。
12. [ ] 文字量大的组件（alert、sidebar、popover）使用 regular。
13. [ ] 同时实现 Clear / Tinted 两种观感（或至少提供设置项）。
14. [ ] 未把变体选择建立在"它现在的颜色好看"上（系统外观会变）。
15. [ ] 深色/浅色两套参数都有定义，没有硬编码十六进制颜色。

## C. 光学与视觉（10 条）

16. [ ] 有模糊（20–30px 档位）与饱和提升（160%–200%）。
17. [ ] 有 1px 亮内描边（rim），方向与光源一致（通常左上）。
18. [ ] 有外描边或落影，玻璃与内容之间有明确分离。
19. [ ] 边缘存在折射/位移（哪怕很轻微），不只是模糊。
20. [ ] 折射带宽限制在边缘 8–14px，中心区域保持清晰。
21. [ ] 有镜面高光，位置与光源逻辑一致。
22. [ ] 桌面端指针高光跟随指针（且无过渡延迟）。
23. [ ] 玻璃的亮度适应背景：浅背景上偏亮、深背景上偏暗。
24. [ ] 圆角符合同心规则（inner ≈ outer − padding）。
25. [ ] 图标/插画未烘焙阴影与高光（避免与系统打光打架）。

## D. 对比与可读性（8 条）

26. [ ] 玻璃上的正文对比 ≥ 4.5:1，大字 ≥ 3:1。
27. [ ] 用最坏情况背景（纯白 / 纯黑 / 高频花纹）验证过。
28. [ ] 材质上的文字使用高活力颜色（vibrant），不是中灰。
29. [ ] 文字与玻璃边缘距离 ≥ 12px，不落在折射带上。
30. [ ] 增强对比开启时，观感仍成立（描边加深、底色更实）。
31. [ ] 鲜艳的背景色不会让玻璃上的图标消失。
32. [ ] 玻璃上不使用细字重（< 400）的浅色文字。
33. [ ] 各类观感下都不需要用户"用力看"。

## E. 动效与交互（9 条）

34. [ ] 按下反馈在 pointer-down 触发，100ms 内可见。
35. [ ] 拖拽 1:1 跟随，保留抓取点偏移。
36. [ ] 抬手有速度投影，动画可被打断/反向。
37. [ ] 状态切换用形变（移动+尺寸+圆角插值），而非交叉淡入。
38. [ ] 弹簧参数在规范表范围内（response 0.30–0.50、damping 0.80–0.85）。
39. [ ] 减弱动效开启后，形变降级为 100–150ms 淡入，且状态变化仍可感知。
40. [ ] 滚动相关的收缩/展开由滚动位置驱动，不用定时器。
41. [ ] 没有大面积同时进行的玻璃动画（避免掉帧与眩晕）。
42. [ ] 长按、双击、右键等次要手势不会破坏玻璃的形变逻辑。

## F. 无障碍（10 条）

43. [ ] 降低透明度开启 → 玻璃退化为不透明表面，且无残留描边/高光。
44. [ ] 增强对比开启 → 描边与底色对比显著提升。
45. [ ] 减弱动效开启 → 无弹簧、无折射随动、无指针高光过渡。
46. [ ] 命中区 ≥ 44×44（Apple 平台），Web 端 ≥ 44×44 CSS px。
47. [ ] 键盘可完整走查，焦点环清晰且在玻璃上可见。
48. [ ] VoiceOver/TalkBack 不朗读玻璃材质本身。
49. [ ] 支持动态字体/字号放大，放大后玻璃不裁切内容。
50. [ ] 支持 RTL，镜面高光方向随语言/光源逻辑调整。
51. [ ] 色盲模拟下玻璃上的状态色仍可区分（不单靠颜色）。
52. [ ] 儿童/老年/低视力用户场景实测通过（真机、真环境光）。

## G. 性能（6 条）

53. [ ] 移动端滚动时帧率 ≥ 55fps。
54. [ ] 一屏模糊层面积占比 < 30%。
55. [ ] 滚动列表项内部不使用 backdrop-filter / BackdropFilter。
56. [ ] 低端设备/低内存时自动降级（去折射、去模糊）。
57. [ ] 位移滤镜只作用于静态装饰层，且启用了 `contain: paint`。
58. [ ] Web 端首屏无因 SVG 滤镜导致的明显掉帧（用 Performance 面板验证）。

## H. 测试矩阵（提测必跑）

| 维度 | 取值 |
| --- | --- |
| 外观 | 浅色 / 深色 |
| 观感偏好 | Clear / Tinted |
| 无障碍 | 默认 / 降低透明度 / 增强对比 / 减弱动效 |
| 光照 | 室内 / 户外强光 / 暗环境 |
| 色域 | sRGB / P3 |
| 字体 | 默认 / 最大动态字体 |
| 设备 | 高端 / 中端 / 低端（含 4GB 内存以下 Android） |
| 输入 | 触摸 / 鼠标 / 键盘 / 辅助开关 |
