# 02 · 设计规范与 Token

本文件把 01 里的原则变成可执行参数。**标注 [建议] 的数值是本喵按工程实践给的区间，不是 Apple 公布值**；标注 [HIG] 的来自 Apple 官方文档原文。

---

## 1. 三层材质语义（先定层级，再谈参数）

| 层 | 名称 | 内容 | 材质 | 能否用 Liquid Glass |
| --- | --- | --- | --- | --- |
| L0 | 内容层 Content | 正文、图片、列表、卡片、页面背景 | 标准材质（ultraThin / thin / regular / thick）或纯色 | 否 [HIG] |
| L1 | 功能层 Functional | 标签栏、工具栏、侧边栏、悬浮操作按钮、分段控件 | Liquid Glass regular | 是，主要战场 |
| L2 | 瞬时层 Transient | Sheet、Popover、Alert、菜单、操作中的 slider/toggle | Liquid Glass regular（少数 clear） | 是，且必须与 L1 视觉区分 |

规则：
- L1 元素永远浮在 L0 之上，滚动内容从下方穿过并出现**滚动边缘效果**（边缘模糊 + 渐隐）。
- **禁止玻璃叠玻璃**：L2 不要直接压在 L1 玻璃上（若必须，使用同一个 `GlassEffectContainer` / 同一 `isolation` 上下文，让它们融合为一块）。
- 一屏独立玻璃层**不超过 3–5 个** [建议]。

## 2. 变体矩阵

| 变体 | 触发条件 | 不透明度基调 | 模糊 | 用于 |
| --- | --- | --- | --- | --- |
| regular · light | 浅色外观 | 白 62–78% | 20–30px | 浅色模式默认 |
| regular · dark | 深色外观 | 黑 45–60% | 20–30px | 深色模式默认 |
| regular · contrast | 增强对比开启 | 底色不透明 + 描边加深 | 略降 | 无障碍 |
| clear | 视觉丰富背景（照片/视频） | 不透明度 15–30% | 小或无 | 媒体上浮层 |
| clear + dim | 背景偏亮 [HIG] | 追加 35% 深色压暗层 | 小 | 媒体上浮层（亮背景） |
| tinted（用户偏好） | 系统 Tinted 选项 | 在 regular/clear 基础上抬升不透明度、对比 | 保持 | 全系统一致性 |
| solid（回退） | 降低透明度开启 | 100% 不透明 | 无 | 所有场景的兜底 |

## 3. 视觉参数表

### 3.1 表面（surface）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| blur（模糊） | 20 / 24 / 30px（sm / md / lg） | 越大越"厚"，文字越多用越大 |
| saturation（饱和） | 160% / 180% / 200% | 让背景色透过时保持鲜亮，是玻璃"通透感"的关键 |
| brightness | 1.0 / 1.06 | 轻微提亮，避免玻璃显脏 |
| base 底色 | 白 70% / 黑 52% | 与外观绑定，不要写死颜色 |
| 内描边（rim） | 1px，白 55%–70% | 玻璃的"厚度"来自这条边 |
| 外描边 | 1px，黑 8%–12%（深色模式下换成白 10%） | 与内容的分离感 |
| 落影 | 0 8px 24px rgba(0,0,0,.16)；暗色模式减弱 30% | 不要用大范围黑雾 |

### 3.2 折射（refraction）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 位移强度 scale | 14–20（默认 16） | 太小无感，太大像水波；示例位移图带宽 22%–78% |
| 影响带宽 | 边缘 8–14px 内 | 只在边缘弯曲，中心保持清晰 |
| 色散（chromatic） | R/G/B 三通道 scale 差 2–6 | 伪造玻璃边缘的彩色偏移，是"高级感"来源 |
| 应用对象 | 仅装饰性玻璃层 | 位移滤镜成本高，不要作用于整屏 |

### 3.3 高光（specular）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 静态高光 | 左上 45° 白 55% → 右下透明，宽 1–2px | 模拟固定光源 |
| 指针高光 | 半径 120–200px 径向渐变，跟随指针 | 桌面端 hover / 移动端触摸点 |
| 高光透明度 | 静态 0.35–0.55，跟随 0.18–0.30 | 过高会显油 |

### 3.4 圆角与同心（concentricity）

| 参数 | 值 |
| --- | --- |
| 小控件（按钮、chip） | 10–14px（或全圆角 capsule） |
| 卡片 / 面板 | 22–28px |
| 浮层 / Sheet | 28–34px |
| 标签栏（胶囊） | 高度 / 2（capsule） |
| 同心公式 | `inner = outer − padding`，误差 ±2px |

## 4. 状态矩阵

| 状态 | 表面变化 | 动效 |
| --- | --- | --- |
| default | 基准参数 | — |
| hover（指针） | 底色 +4% 不透明度；指针高光跟随 | 120ms ease-out |
| press / active | 缩放 0.96–0.97；内描边加亮；高光增强 | 80–120ms，按下瞬间即响应 |
| focus（键盘） | 2px 高亮环 + 2px 偏移 | 立即 |
| selected（分段/标签） | 玻璃块移动到目标位置（形变，不是淡入） | spring，response 0.3–0.4s |
| disabled | 不透明度 40%，取消高光与折射 | — |
| 拖拽中 | 玻璃跟随指针，边缘轻微拉伸（scale 1.0→1.02） | 1:1 跟随，无缓动 |

## 5. Token 命名规范

统一前缀 `--lg-`（liquid glass），结构：`--lg-{类别}-{语义}-{状态}`

```
--lg-blur-md
--lg-surface-bg
--lg-surface-bg-clear
--lg-rim-top
--lg-shadow-1
--lg-radius-card
--lg-motion-spring
--lg-tint-accent
```

落地文件：
- [tokens/liquid-glass.tokens.json](tokens/liquid-glass.tokens.json)（机器可读，可喂给 Style Dictionary / Tokens Studio）
- [tokens/liquid-glass.css](tokens/liquid-glass.css)（直接 import 的 CSS 变量 + 工具类）

## 6. 排布与间距

| 项目 | 值 [建议] |
| --- | --- |
| 玻璃容器内边距 | 12 / 16 / 20px |
| 玻璃控件最小命中区 | 44 × 44px（Apple 平台硬性习惯值） |
| 控件间距 | 8 / 12 / 16px |
| 功能层与屏幕安全区间距 | 12–16px |
| 文字与玻璃边缘距离 | ≥ 12px（避免文字压在折射带上看不清） |
| 滚动边缘效果高度 | 56–88px（等于工具栏高度 ± 20%） |

## 7. 一页速查（贴在工位上那种）

```text
层级：功能层才用玻璃 → 内容层用标准材质 → 不许玻璃叠玻璃
观感：半透明底 + 模糊 24 + 饱和 180 + 1px 亮内边 + 边缘折射 + 左上高光
文字：压在玻璃上必须过 4.5:1，否则加压暗层或换 regular
交互：按下即响应（<100ms）、切换用形变不用淡入、指针高光跟随
回退：降低透明度 → 全不透明；减弱动效 → 静态；Tinted 偏好 → 抬不透明度
```
