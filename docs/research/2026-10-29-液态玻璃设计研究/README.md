## 一句话结论

Liquid Glass 不是"毛玻璃皮肤"，而是一套**材质 + 光学 + 层级**的系统规范：它把玻璃的折射（lensing）、镜面高光、自适应染色和形变能力做成**只服务于交互层**的动态材质，判断一个实现对不对，先看它"该不该出现"，再看它"像不像玻璃"。

## 30 秒速览

- **定位**：功能层材质（导航、控件、浮层），浮在内容层之上；内容层用标准材质。
- **两个变体**：`regular`（模糊+亮度调整，绝大多数系统组件）与 `clear`（高度透明，仅用于媒体/照片等视觉丰富背景之上）。
- **五要素光学模型**：实时渲染与镜面高光、边缘透镜折射、自适应染色、上下文形变、层级浮起（含滚动边缘效果 scroll edge effect）。
- **最重要的一条禁令**：不要在内容层使用 Liquid Glass。用错层级比做不出效果更严重。
- **可达性**：可由系统设置（Clear / Tinted，iOS 26.1+）与无障碍开关（降低透明度、增强对比、减弱动效）改变外观；实现必须为这几种状态准备回退。
- **常见误用**：玻璃叠玻璃、四处滥用、在文字密集区域铺玻璃、把阴影/高光烘进图标或素材。

## 怎么用这套东西

1. 先读 01，建立"该不该用"的判断力；
2. 设计直接拿 02 的参数表和 Token 开工；
3. 工程按 03 选平台实现（表里有迁移映射）；
4. 动效按 04 的参数落地，不要自创曲线；
5. 提测前用 05 逐条过一遍；
6. 需要给客户/老板演示，打开 demo/liquid-glass-demo.html。

## 版本与适用范围声明

- 本包基于公开资料（Apple 官方 HIG / WWDC25 场次 / 公开报道）整理，**参数表里的具体数值（模糊半径、rim 宽度、弹簧参数、间距）是本喵按工程实践给出的建议区间，不是 Apple 公布的数字**；凡是 Apple 官方原文的规则，均在 01/02 中以引用形式标注。
- Apple 未公开 Liquid Glass 的渲染实现细节；所有 Web / Android / Flutter 实现都是**光学近似**，一致性目标是"观感与行为对齐"，不是像素级复刻。
