# 04 · 动效与交互规范

Liquid Glass 的"液"是动效给的：材质负责"像玻璃"，行为负责"像液体"。

---

## 1. 四条底层原则

1. **按下即响应**：反馈出现在 pointer-down 的瞬间（< 100ms），不要等抬手或 click 事件。延迟一旦可感知，直接感就崩了。
2. **1:1 跟随**：拖拽/滑动时元素与指针同步位移，并保留"抓取点偏移"，不要吸附到中心。
3. **速度感知与投影**：抬手时用最近几帧的速度决定动画去向与时长，让惯性延续下去。
4. **可打断、可反向**：任何进行中的动画都能被新的输入接管；这就是弹簧比关键帧更合适的原因。

---

## 2. 参数表

| 场景 | 参数 | 值 | 备注 |
| --- | --- | --- | --- |
| 悬停（hover） | 时长 / 曲线 | 120ms / ease-out | 只改不透明度与高光 |
| 按下（press） | 时长 / 缩放 | 100ms / 0.96–0.97 | pointer-down 触发 |
| 抬起反弹 | 弹簧 response / damping | 0.30–0.40 / 0.80–0.85 | 有轻微过冲 |
| 形变切换（morph） | 弹簧 response | 0.40–0.50 | 距离长时略慢 |
| 玻璃融合 / 分裂 | 弹簧 response | 0.45 | 配合 `GlassEffectContainer` spacing |
| 指针高光跟随 | 无缓动 / 直接写变量 | 每帧 | 永不加过渡，否则"黏" |
| 滚动收缩（tab bar minimize） | 与滚动位置绑定 | 位移驱动 | 不要用定时器 |

## 3. CSS 落地

### 3.1 弹簧缓动（`linear()`）

```css
:root {
  /* response 0.34 / damping 0.82 的弹簧采样 */
  --lg-spring: linear(0, 0.0039 0.9%, 0.0157 1.8%, 0.0625 3.5%, 0.246 6.6%,
                      0.463 8.7%, 0.877 12.4%, 1.008 14.6%, 1.048 16.5%,
                      1.022 20.2%, 0.996 24.3%, 0.999 30.2%, 1);
}
.lg-btn { transition: transform 100ms cubic-bezier(0.2, 0, 0, 1); }
.lg-btn:active { transform: scale(0.97); }
```

### 3.2 形变切换（不做交叉淡入）

```css
/* 选中块用位移 + 尺寸过渡；圆角随尺寸变化插值，保持同心 */
.lg-segment__thumb {
  transition: transform 420ms var(--lg-spring), width 420ms var(--lg-spring);
}
```

```js
// FLIP：先记录旧位置，改布局，再用 transform 动画回去
function morph(el, mutate) {
  const first = el.getBoundingClientRect();
  mutate();
  const last = el.getBoundingClientRect();
  el.animate(
    [{ transform: 'translate(' + (first.left - last.left) + 'px,' + (first.top - last.top) + 'px)' },
     { transform: 'none' }],
    { duration: 420, easing: 'cubic-bezier(0.2, 0, 0, 1)' }
  );
}
```

### 3.3 拖拽：1:1 + 速度投影

```js
let samples = [];
function onMove(e) {
  samples.push({ t: performance.now(), x: e.clientX });
  if (samples.length > 5) samples.shift();
  el.style.transform = 'translateX(' + (e.clientX - startX) + 'px)';
}
function onUp() {
  const first = samples[0], last = samples[samples.length - 1];
  const v = (last.x - first.x) / Math.max(1, last.t - first.t);   // px/ms
  const projected = last.x + v * 200;                             // 投影 200ms
  el.style.transition = 'transform 500ms var(--lg-spring)';
  el.style.transform = 'translateX(' + (projected - startX) + 'px)';
}
```

## 4. 形变（morph）在 Apple 原生

```swift
@Namespace private var ns

GlassEffectContainer(spacing: 20) {
    HStack {
        ForEach(tabs) { tab in
            Button(tab.title) { withAnimation(.spring(response: 0.45, dampingFraction: 0.82)) { selected = tab } }
                .padding(.horizontal, 16)
                .glassEffect(.regular.interactive())
                .glassEffectID(tab.id, in: ns)
        }
    }
}
```

规则：
- 只要玻璃元素会**出现/消失/移动**，就必须有稳定 ID，否则系统只能做淡入淡出，看起来廉价；
- 相邻玻璃元素的 `spacing` 决定融合阈值：想让它们在接近时合并成一个，把 spacing 放大。

## 5. 无障碍回退

```css
@media (prefers-reduced-motion: reduce) {
  .lg-btn { transition: opacity 100ms linear; }
  .lg-btn:active { transform: none; }
  .lg-segment__thumb { transition: opacity 120ms linear; }
  .lg-specular::after { transition: none; }
}
```

- 减弱动效 ≠ 全部取消：保留 100–150ms 的淡入淡出，让状态变化仍可感知；
- 关闭形变与弹簧，但**保留层级与对比**；
- 系统"移除动画"（Android Animator duration scale = 0、iOS 减弱动态效果）必须被侦测并生效。

## 6. 反面清单（AI 感与廉价感的来源）

| 反模式 | 为什么错 |
| --- | --- |
| 所有元素都加 hover 上浮 + 缩放 | 玻璃很贵，到处都是就变成塑料 |
| 用 1s 的缓入缓出做形变 | 液体的切换是干脆的，慢= 拖沓 |
| 切换用交叉淡入 | 玻璃是有形状的实体，实体应该移动 |
| 高光加过渡 | 指针高光必须 1:1 跟随，加过渡就像贴了一张会滞后的小纸片 |
| 弹跳系数过大（damping < 0.6） | 果冻感，不是玻璃感 |
| 滚动时玻璃层抖动 / 掉帧 | 材质成本被低估，必须限流或降级 |
