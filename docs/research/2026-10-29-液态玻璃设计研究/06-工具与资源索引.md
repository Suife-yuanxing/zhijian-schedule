## 4. 工具清单（开工前先装）

1. **Xcode 26+**（含 Icon Composer；SwiftUI 玻璃 API 需要 iOS/macOS 26 SDK）
2. **Icon Composer**：分层图标 → `.icon`，预览所有外观模式
3. **SF Symbols 7 应用**：符号检索与动效预览
4. **Apple Design Resources**：Sketch / PSD / AI 设计库与图标模板
5. **Figma + 位移贴图插件**：制作折射用的位移贴图（中间 128 灰、四边方向渐变）与高光贴图
6. **Chrome DevTools → Rendering 面板**：模拟 `prefers-reduced-transparency`、`prefers-contrast`、`prefers-reduced-motion`
7. **Android Studio AGSL 预览**（体素化 shader 调试）与低端机真机
