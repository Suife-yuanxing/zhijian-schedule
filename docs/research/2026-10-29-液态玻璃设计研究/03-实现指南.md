# 03 · 实现指南（全端）

目标：让每个平台都拥有"功能层玻璃 + 自适应 + 可回退"的同一套观感。**Apple 原生（iOS/macOS 26+）是唯一的一等公民实现**，其它平台是光学近似。

---

## 0. 平台总览

| 平台 | 方案 | 折射（关键特征） | 保真度 | 备注 |
| --- | --- | --- | --- | --- |
| SwiftUI / UIKit / AppKit（26+） | 系统材质 API | 系统内建 | 100% | 一行 API 即可，系统自动适配 Clear/Tinted、降低透明度 |
| Web（Chromium 优先） | `backdrop-filter` + SVG `feDisplacementMap` | 自实现（位移贴图） | 70–85% | 需处理性能与回退 |
| Web（Safari 26+） | 同上，`backdrop-filter` 支持良好 | 自实现 | 70–85% | 部分上下文对 SVG 滤镜支持受限 |
| Android（Compose） | `RenderEffect`（API 31+）/ AGSL `RuntimeShader`（33+） | 自实现（shader） | 60–80% | 低端机需降级为纯半透明 |
| Flutter | `BackdropFilter` + `FragmentShader` | 自实现 | 60–80% | 全屏 BackdropFilter 开销大 |
| 小程序 / 网页内嵌 | 简化版：半透明 + 模糊 + 高光 | 通常放弃 | 50–70% | 只保留层级感与高光 |

统一原则三条：
1. **层级第一**：只给功能层加玻璃。
2. **回退必做**：降低透明度 / 减弱动效 / 低端设备 → 退化为不透明或静态。
3. **一致性只看行为**：切换用形变、按下即响应、指针高光跟随 —— 这三条跨端必须一致。

---

## 1. Apple 原生（SwiftUI）

### 1.1 最小可用

```swift
import SwiftUI

struct GlassCard: View {
    var body: some View {
        Text("Hello, Liquid Glass")
            .font(.headline)
            .padding(.horizontal, 20)
            .padding(.vertical, 14)
            .glassEffect()                       // 默认：regular 变体 + Capsule 形状
    }
}
```

### 1.2 形状、变体、着色、交互

```swift
// 自定义形状（同心圆角：inner = outer - padding）
.glassEffect(in: .rect(cornerRadius: 16))

// 交互态：按下/悬停时玻璃自身响应
.glassEffect(.regular.interactive())

// 着色：用语义色，不要用写死的十六进制
.glassEffect(.regular.tint(.blue))

// clear 变体（仅用于照片/视频之上），背景偏亮时补压暗层
.glassEffect(.clear)
// 压暗层遵循 HIG 的 35% 深色建议
```

### 1.3 多玻璃元素：容器 + 融合 + 形变

多个玻璃元素**必须**放进 `GlassEffectContainer`，否则会出现渲染重复与融合错误。

```swift
@Namespace private var ns

GlassEffectContainer(spacing: 24) {
    HStack(spacing: 24) {
        ForEach(actions) { action in
            Button(action.title) { action.run() }
                .padding(12)
                .glassEffect(.regular.interactive())
                .glassEffectID(action.id, in: ns)      // 形变身份
        }
    }
}

// 需要把多个玻璃合成一块（例如分段控件）时：
.glassEffectUnion(id: "segment", namespace: ns)
```

- `spacing` 越大，元素越"容易"在靠近时融合；调这个值来控制合并阈值。
- `glassEffectID(_:in:)` 配合 `withAnimation(.spring)` 做形变；切换分区时玻璃块会**移动并变形**，而不是交叉淡入。

### 1.4 按钮样式与系统组件

```swift
Button("主操作") { }.buttonStyle(.glassProminent)   // 同色系高亮玻璃，主操作
Button("次要")   { }.buttonStyle(.glass)            // 中性玻璃胶囊

TabView { ... }                    // 自动获得玻璃标签栏 + 滚动最小化行为
NavigationSplitView { ... }        // macOS / iPadOS 自动玻璃侧边栏
.toolbar { ... }                   // 自动获得滚动边缘效果
```

### 1.5 迁移表（旧 API → Liquid Glass 时代）

| 旧写法 | 新写法 | 说明 |
| --- | --- | --- |
| `.background(.ultraThinMaterial)`（功能层控件） | `.glassEffect()` | 材质语义变了：这是功能层，应该用玻璃 |
| `.background(.regularMaterial)`（页面背景） | 保持 | 内容层继续用标准材质 |
| 自定义胶囊按钮 + 手写模糊 | `.buttonStyle(.glass)` / `.glassProminent` | 交给系统，自动适配无障碍 |
| 自定义标签栏 | `TabView` | 自动玻璃 + 最小化行为 |
| `UIVisualEffectView` + `UIBlurEffect`（控件） | `UIGlassEffect` | UIKit 路径 |
| `NSVisualEffectView`（控件/侧边栏） | `NSGlassEffectView` | AppKit 路径 |
| 手写圆角 12 的按钮放在圆角 28 的卡上 | 改为同心：28 − 16 = 12（按内边距算） | 形状语言一致性 |

### 1.6 UIKit / AppKit 速览

```swift
// UIKit
let effect = UIGlassEffect()          // regular 变体
effect.isInteractive = true
let view = UIGlassEffectView(effect: effect)

// 多个玻璃元素共享渲染
let container = UIGlassContainerEffect()
// AppKit
let glass = NSGlassEffectView()
glass.cornerRadius = 16
```

### 1.7 系统会自动做的事（别自己重复实现）

- 深/浅色、**Clear / Tinted 用户偏好**（iOS/iPadOS 26.1+ 在 Settings > Display & Brightness；macOS 在 System Settings > Appearance）；
- 增强对比、降低透明度；
- 滚动边缘效果；
- 标签栏滚动最小化、控件形变。

你只需要：选对层级、选对变体、别滥用。

## 2. Web：CSS + SVG 位移（重点章节）

Web 没有系统材质，需要三件事叠加：**模糊层 + 折射层 + 高光层**。

### 2.1 第一层：模糊与自适应染色（基础，跨浏览器）

```css
.lg-surface {
  background: rgba(255, 255, 255, 0.70);
  -webkit-backdrop-filter: blur(24px) saturate(180%);
  backdrop-filter: blur(24px) saturate(180%);
  box-shadow:
    inset 1px 1px 0 0 rgba(255,255,255,0.62),   /* 左上镜面高光 */
    inset -1px -1px 1px 0 rgba(255,255,255,0.22),
    0 0 0 1px rgba(0,0,0,0.10),                 /* 外描边 */
    0 8px 24px rgba(0,0,0,0.16);
  border-radius: 26px;
}
```

要点：
- `backdrop-filter` 必须作用在**半透明**元素上，纯透明背景看不出效果；
- `saturate(180%)` 是"通透感"的关键，别省；
- 高光用 inset box-shadow 而不是边框，这样圆角会自动跟随。

### 2.2 第二层：边缘折射（特征层）

思路：用一张**位移贴图**（内部透明、四边有方向渐变的图）驱动 `feDisplacementMap`，让背景在玻璃边缘弯曲。

**关键限制**：Chromium 对 `backdrop-filter: url(#filter)` 的支持并不稳定，Safari/Firefox 更保守。工程上成熟的替代做法是——**复制一份背景，对副本做位移，再用 `clip-path` / 容器裁剪限制在玻璃区域内**。

```html
<svg width="0" height="0" aria-hidden="true">
  <filter id="lg-refraction" x="-20%" y="-20%" width="140%" height="140%">
    <!-- 位移贴图：中间 128 灰（不位移），四边按方向渐变 -->
    <feImage result="map" href="data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='200' height='200'><defs><linearGradient id='h' x1='0' x2='1'><stop offset='0' stop-color='%23008080'/><stop offset='.22' stop-color='%23808080'/><stop offset='.78' stop-color='%23808080'/><stop offset='1' stop-color='%23ff8080'/></linearGradient><linearGradient id='v' x1='0' y1='0' x2='0' y2='1'><stop offset='0' stop-color='%23800080'/><stop offset='.22' stop-color='%23808080'/><stop offset='.78' stop-color='%23808080'/><stop offset='1' stop-color='%2380ff80'/></linearGradient></defs><rect width='200' height='200' fill='%23808080'/><rect width='200' height='200' fill='url(%23h)'/></svg>"/>
    <feDisplacementMap in="SourceGraphic" in2="map" scale="16"
                       xChannelSelector="R" yChannelSelector="G"/>
  </filter>
</svg>
```

位移贴图的读法：R 通道控制水平位移量、G 通道控制垂直位移量，128 为不动，小于 128 向一侧、大于 128 向另一侧。

**色散（可选加分项）**：把同一份内容做三次位移，scale 分别取 16 / 18 / 20，再用 `feBlend mode="screen"` 合成，就能得到玻璃边缘的轻微彩边 —— 这是"真玻璃感"最廉价的来源。具体做法见 [demo/liquid-glass-demo.html](demo/liquid-glass-demo.html) 的实现。

### 2.3 第三层：镜面高光与指针跟随

```css
.lg-specular::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background: radial-gradient(circle 160px at var(--lg-mx, 30%) var(--lg-my, 0%),
              rgba(255,255,255,0.24), transparent 70%);
  opacity: 0; transition: opacity 120ms ease-out;
}
.lg-specular:hover::after { opacity: 1; }
```

```js
// 每帧只写两个 CSS 变量，不要每帧改样式表
el.addEventListener('pointermove', (e) => {
  const r = el.getBoundingClientRect();
  el.style.setProperty('--lg-mx', ((e.clientX - r.left) / r.width * 100) + '%');
  el.style.setProperty('--lg-my', ((e.clientY - r.top) / r.height * 100) + '%');
}, { passive: true });
```

### 2.4 容器融合（对应 GlassEffectContainer）

多个玻璃元素相邻时，用同一个隔离上下文，避免互相采样造成重影：

```css
.lg-container { isolation: isolate; }        /* 隔离混合上下文 */
.lg-container .lg-surface { position: relative; }
```

### 2.5 无障碍与回退（必做）

```css
@media (prefers-reduced-transparency: reduce) {
  .lg-surface {
    background: #f2f2f7;
    -webkit-backdrop-filter: none; backdrop-filter: none;
  }
}
@media (prefers-contrast: more) { .lg-surface { outline: 1px solid currentColor; outline-offset: -1px; } }
@media (prefers-reduced-motion: reduce) { .lg-surface { transition: none; } }
```

同时在页面上提供 **观感切换**（Clear / Tinted），对应 iOS 26.1 的用户偏好；默认可以是 Tinted 偏保守。

### 2.6 性能清单

| 风险 | 处理 |
| --- | --- |
| 大面积 `backdrop-filter` | 只对小的功能层用，别做全屏玻璃 |
| 位移滤镜重绘 | 只作用于静态装饰层；给容器加 `contain: paint` / `will-change: transform`（用完即撤） |
| 滚动列表内玻璃 | 禁止；要么整条列表做一张玻璃（sticky 顶栏），要么每项用纯色 |
| 移动端低端机 | 用 `matchMedia` + 设备内存/核心数判断，主动降级为不透明 |
| 层叠过多 | 一屏玻璃层 ≤ 3–5；禁止玻璃叠玻璃 |

### 2.7 参考实现思路（可对照学习）

- SVG 位移 + 背景副本方案：GitHub `rizroze/liquid-glass`（三通道位移做色散）
- WebGL 着色器方案：`liquid-glass-js`（实时折射 + 嵌套玻璃系统，子玻璃采样父容器已渲染结果）
- 教程级拆解：LogRocket《How to create Liquid Glass effects with CSS and SVG》（含 Figma 里制作位移贴图/高光贴图的流程）

## 3. Android / Jetpack Compose

### 3.1 模糊：分档降级

| Android 版本 | 手段 | 效果 |
| --- | --- | --- |
| 12（API 31）+ | `Modifier.graphicsLayer { renderEffect = RenderEffect.createBlurEffect(...) }` | 可对自身/背景模糊 |
| 13（API 33）+ | AGSL `RuntimeShader`（`Modifier.drawWithContent`） | 可做折射、色散、噪声 |
| 更低 | 半透明 + 高光描边 | 只有层级感 |

社区库思路（如 haze 类库）是：**把背景内容渲染到离屏，再对离屏纹理做模糊/位移采样**，这样才能实现真正的"背景模糊"而不是"自身模糊"。

### 3.2 骨架

```kotlin
@Composable
fun GlassSurface(
    shape: Shape = RoundedCornerShape(26.dp),
    content: @Composable () -> Unit
) {
    val density = LocalDensity.current
    Box(
        Modifier
            .clip(shape)
            .background(Color.White.copy(alpha = 0.70f))
            .then(
                if (Build.VERSION.SDK_INT >= 31) Modifier.graphicsLayer {
                    renderEffect = RenderEffect
                        .createBlurEffect(24f * density.density, 24f * density.density,
                                          RenderEffect.createBlurEffect(0f, 0f, Shader.TileMode.CLAMP))
                        .asComposeRenderEffect()
                } else Modifier
            )
            .border(1.dp, Color.White.copy(alpha = 0.62f), shape)   // rim 高光
            .shadow(8.dp, shape)
    ) { content() }
}
```

### 3.3 Android 注意事项

- 真正的背景模糊需要把背景画到 `GraphicsLayer` 再读回纹理，**不要对每个列表项做**；
- AGSL 折射需要 Android 13+，必须做版本分支；
- 深色模式、系统字体缩放、"移除动画"（Animator duration scale = 0）都要测；
- 低端机（内存 < 4GB）建议直接关闭折射，仅保留半透明 + rim。

## 4. Flutter

```dart
class GlassSurface extends StatelessWidget {
  const GlassSurface({super.key, required this.child});
  final Widget child;

  @override
  Widget build(BuildContext context) {
    return ClipRRect(
      borderRadius: BorderRadius.circular(26),
      child: BackdropFilter(
        filter: ImageFilter.blur(sigmaX: 24, sigmaY: 24),
        child: Container(
          decoration: BoxDecoration(
            color: Colors.white.withOpacity(0.70),
            borderRadius: BorderRadius.circular(26),
            border: Border.all(color: Colors.white.withOpacity(0.62), width: 1),
          ),
          child: child,
        ),
      ),
    );
  }
}
```

- `BackdropFilter` 极耗性能：**不要放进滚动列表**，不要全屏使用；
- 想做出边缘折射，需要 `FragmentShader`（GLSL）采样背景纹理；
- Flutter 的 `ClipRRect + BackdropFilter` 组合会产生额外的离屏渲染，层数越多越慢，一屏 ≤ 2 层。

## 5. 跨端一致性对照表

| 行为 | Apple 原生 | Web | Compose | Flutter |
| --- | --- | --- | --- | --- |
| 功能层玻璃 | `.glassEffect()` | `backdrop-filter` + 高光/折射 | `RenderEffect` / AGSL | `BackdropFilter` |
| 多元素融合 | `GlassEffectContainer` | `isolation: isolate` | 共享离屏纹理 | 共享 `RepaintBoundary` |
| 形变切换 | `glassEffectID` + spring | spring + FLIP | animateDpAsState/spring | `AnimatedPositioned` |
| 用户偏好 Clear/Tinted | 系统设置自动 | 页面内切换 + localStorage | 应用内设置 | 应用内设置 |
| 降低透明度 | 系统自动 | `prefers-reduced-transparency` | 无障碍服务判断 | `MediaQuery.disableAnimations` 类比判断 |
| 滚动边缘效果 | 系统内建 | `mask-image` 渐隐 + 模糊 | 顶部 `Brush.verticalGradient` 蒙版 | `ShaderMask` |

## 6. 验收脚本（最小可执行）

1. 打开页面/App，确认玻璃只出现在功能层；
2. 把背景换成**纯白照片**和**深黑照片**各测一次，检查文字对比度（目标正文 4.5:1）；
3. 打开"降低透明度"，确认玻璃退化为不透明且没有残留描边；
4. 打开"减弱动效"，确认形变降级为淡入；
5. 切换 Clear / Tinted，确认两者都可用且都不难看；
6. 在滚动列表里滚动，确认玻璃层帧率不下降（移动端 ≥ 55fps）；
7. 用键盘 Tab 走一遍，确认焦点环清晰、命中区 ≥ 44px。
