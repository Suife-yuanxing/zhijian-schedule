# 2026-10-31 · 「我的」入口页玻璃动效迭代（设计稿）

## 背景

「我的」页四个入口（导入课表 / 成绩查询 / 考试安排 / 高级设置）的打开动效是自研的
卡片展开式容器变换（`ProfileEntryPage` cover 裁剪展开 + `ProfileEntryExitOverlay`
快照收回），骨架已稳。本轮按「玻璃材质强化」方向迭代：**不动展开/收回的几何运动**，
在其上叠加材质层（景深磨砂、边缘流光、内侧高光、着地果冻），并把按压反馈与二级页
内部入场补齐。

设计参照：M3 编排原则（容器先动、内容就位）、iOS 26 Liquid Glass「材质像玻璃、
行为像液体」、本项目 `docs/research/2026-10-29-液态玻璃设计研究/04-动效与交互规范.md`
（弹簧 response 0.4–0.5 / damping ≥ 0.6，高光不加过渡）。

## 方案

### 1. 背景景深磨砂（展开时「我的」页退后）

- `ProfileEntryTransitions` 新增 `backdrop: Float`（0..1），由进入/返回动画驱动，
  页面停留期间恒为 1。
- `ProfileScreen` 根 Column 挂 `Modifier.entryBackdrop(transitions)`：
  - **blur**：`graphicsLayer { renderEffect = BlurEffect(16dp·b) }`，仅 API 31+；
  - **scrim**：`drawWithContent` 叠 `colors.bg` 压暗，alpha ≤ 0.25·b，全版本生效；
  - 状态读取全部放在绘制/图层阶段（graphicsLayer lambda、drawWithContent），
    不逐帧重组 ProfileScreen。
- 驱动方三处、互斥写入：进入（ProfileEntryPage，跟随 enter 进度）、中途返回
  （跟随反向收回）、整页快照回收（ExitOverlay，400ms EaseOut 释放）。
- 「移除动画」（ANIMATOR_DURATION_SCALE = 0）时整层跳过——纯装饰动效。

### 2. 展开容器的玻璃质感（不几何变化，只加绘制）

`profileEntryForward` 的 draw 阶段新增两层，全部参数由 `ProfileEntryGeometry`
纯函数给出、可单测：

- **内侧流光**：对角线白色光带随进度扫过容器，alpha 中段见峰（峰值 ≈0.09）、
  两端归零——玻璃被「擦亮」一下，展开完成时完全消失；
- **边缘扫光**：1.5dp 描边上叠一道沿周向行进的 sweepGradient 高光段，
  alpha 同样中段峰、端点归零，与既有 1dp border 描边叠加。

### 3. 着地果冻（返回收进卡片后卡片有接收反馈）

- `ProfileEntryTransitions.finishExit` / 中途返回收拢结束 → 记
  `receivedKey` + 递增 `receivedSerial(key)`；
- `ProfileEntryAnchor` 读序号：快照落进卡片的同一帧卡片 scale 抬到 1.03，
  随后 `Motion.CatchSpring`（damping 0.55 / stiffness 520，过冲 ≈12%）软着陆回 1，
  读作「卡片把页面接住、轻微鼓了一下」。中途返回（abort）路径同样触发。
- 「移除动画」时直接跳过。

### 4. 入口卡按压交互

- `HeroEntryCard`：图标底座按下缩到 0.9、松手 `Motion.PressSpring` 回弹；
- `GroupedEntryRow`：图标底座同款按压响应；行按住时尾部箭头右移 3dp
  （速度感暗示「要去哪」），松手弹回。

### 5. 二级页内部

- **成绩页**：概览 / 趋势 / 学期胶囊三个结构块在**首次数据到达**时级联入场
  （`StaggerIn`，仅一次，切学期筛选不重播）；趋势卡的绩点条首次出现时从 0
  弹簧生长到位（`Motion.CascadeEnter`）。
- **考试页**：分组标题 `StaggerIn`、考试行 `cascadeIn`（步进 24ms、封顶 240ms），
  每次推入播放一次（与设置页既有节奏一致）；考试行加 `pressScale` 按压反馈。
- **设置页**：已有 `StaggerIn` 入场，不动。
- 教务导入（WebView）链路保持硬切——WebView 层级约束是既有结论，不碰。

## 边界情况

- **锚点几何安全**：磨砂/流光/压暗均不改变任何布局与 bounds，入口卡矩形
  （`boundsInWindow` 上报）全程稳定，收回落点不会漂移；
- **展开中途返回**：enter 反向收回，backdrop 跟随回落，abort 结束触发着地；
- **API < 31**：blur 为 no-op，压暗 scrim 独立生效，视觉降级但层级感保留；
- **JW 二级链**（profile_jw_import / scripts）：backdrop 停在 1 但「我的」页不在
  组合里，无渲染成本；返回 importer 再返回时由浮层正常释放。

## 验证

- `ProfileEntryGeometryTest` 补流光/扫光 alpha 曲线端点与单调性用例；
- 全量单测 + 编译；
- 模拟器逐条过四入口：展开材质、返回磨砂、着地回弹、成绩/考试入场。
