# 三套主题重构 · 设计文档

日期：2026-10-29
状态：**已落地**（token 与渲染链路均已改动，单测通过）
范围：清爽极简 / 墨夜纯黑 / 多彩活泼 —— 三套全部重构；其余三套（纸本暖白、动态取色、液态玻璃）行为零变化

---

## 0. 为什么要重构：三个硬伤

先把问题钉死，避免重构变成换色。

### 0.1 撞脸：五套主题共享同一个蓝

| 现有主题 | 底色 | 强调色 | 圆角(block/card/sheet) | 气质 |
|---|---|---|---|---|
| 纸本暖白 | #FAF6EF | #D97757 | 10/16/20 | 暖纸+陶土，衬线 |
| 动态取色 | 跟随壁纸 | 跟随壁纸 | 12/16/24 | 系统感 |
| 清爽极简 | #FFFFFF | **#007AFF** | 12/20/28 | iOS 目录 |
| 墨夜纯黑 | #000000 | **#6BA0FF** | 8/14/18 | 通用暗色 |
| 多彩活泼 | #F7F8FC | **#3A7DFF** | 16/20/24 | 通用年轻向 |
| 液态玻璃 | #F6F7F9 | #2F7BFF | 16/20/26 | 纯净+浮岛 |

待重构的三套强调色分别是 007AFF / 6BA0FF / 3A7DFF，加上液态玻璃，五套共享同一个品牌蓝。
主题切换只换得了底面，换不了性格。

### 0.2 语义空转

「清爽极简」= 白底 + 蓝 + 大圆角，「多彩活泼」= 糖果色块，「墨夜纯黑」= 纯黑 + 高对比。
这三条是任何 App 都能套的模板，和「课程表 / 时间块」零关联。

### 0.3 最致命的一条：主题改不动课块

这是本次重构真正的主线，也是之前几次「换皮」不生效的根因。

`core/theme/Tone.kt` 里的 `courseTone(source, isDark)` **只接收源色与明暗**，与主题无关。
而课块的实际渲染（`CourseBlock.kt`）是：

```kotlin
.background(tone.container)          // 卡面：由 courseTone 派生
.border(1.dp, tone.line, shape)      // 描边：同色系深一档
Text(color = tone.ink)               // 正文
```

于是**同一门课在六套主题里渲染出一模一样的卡面**。主题切过去，只剩页面底色变了，
课表主体——那些铺满屏幕的课程块——纹丝不动。三项重构如果只改 `CourseColors` 八字段，
本质上就是换了个页面底色，用户不会觉得「换了一套风格」。

### 0.4 附带发现：`blockStyle` 是死字段

`ThemePreset.blockStyle`（`fillAlphaLight / fillAlphaDark / barWidthDp`）描述的是早期的
「透明填充 + 左色条」渲染。课块后来改成了「同色系容器 + 1dp 同色描边」（`CourseBlock.kt`
类注释写着「去掉左色条」），**这三个参数从此没有任何渲染消费点**。

此前所有主题的 token 表里列的「色条宽度 2.5 / 3 / 4dp」都是纯注释，调了不会有任何效果。
本次重构保留字段以兼容旧预设字面量，但在注释里明确标了废弃，并把真正的差异化参数
放在新引入的 `CourseToneBias` 上。

### 0.5 工程债

- 代码注释已记录：「清爽极简」未选中标签对比度只有 2.99 / 3.26，低于正文门槛 4.5；
- 墨夜纯黑用 `#FFFFFF` 作正文，在纯黑底上产生 halation（光晕），对散光用户尤其刺激；
- 真黑底没有阴影可落，靠 `surface #0F0F10` 这种「比黑更黑不存在」的灰阶硬撑层级，界限感弱。

重构目标：**三套主题各拿到一个只属于课程表的隐喻 + 一套能自洽的色与形 + 一个真正改得动课块的参数，并且把对比度债还掉。**

## 1. 调研锚点：2025-2026 在讲什么

不抄趋势，只取能落到 token 上的结构性结论。

### 1.1 Material 3 Expressive（Android 16）

Google 在 I/O 2025 发布，随 Android 16 落地，是 2021 年 Material You 之后最大一次视觉改动。最实质的一条是
**动效从「固定时长 + 贝塞尔曲线」换成弹簧物理（stiffness / damping）**：

- 手势被打断时，动画能从当前速度反向，而不是跳回起点；
- 同一套 spring 定义在 60/90/120Hz 上表现一致；
- 官方内部测试：中断手势的感知抖动降低 32%。

意义：**三套主题的个性应该由「动」来分层，而不是每套塞一个新组件**。

### 1.2 New Brutalism / 高对比回潮

粗描边、可见网格线、超大字号、非常规撞色回潮；2026 走向「bold 但可访问」。
落到本 App：**明确描边 + 强化结构**可以作为「文具盒」的骨架，而不是靠饱和度取胜。

### 1.3 True Black / AMOLED 的正确做法

参考 [vocab.design · True black theme](https://vocab.design/true-black-theme)：

- 真黑丢了「地板」——深色模式的层级本来靠 elevation overlay（白膜随高度加深），纯黑下
  第一级还有，再往上没有落脚点，**阴影在纯黑上什么也投不出来**；
- 通行修法：**给每个 surface 一条 hairline 描边**，于是真黑界面看起来是「画出来的」而不是「叠出来的」；
- 两个真实副作用：**black smearing**（OLED 像素从全关恢复慢，快速滚动纯黑会拖影）与
  **halation**（纯白字在纯黑上发晕，散光用户更明显）；
- 结论：真黑应当作为「第三档」而非唯一暗色，且**不要把 `#FFFFFF` 配纯黑**，用 `#E8EAEF` 一类灰白。

直接决定了「灯下」的两条硬规则：真黑 + 暖白字 + 全 surface 描边。

### 1.4 Dopamine Design（多巴胺风）

2025-2026 主趋势之一：高饱和霓虹、大胆排版、能量感。参考
[stylekit · Dopamine Design](https://www.stylekit.top/en/styles/dopamine-design) 的色板：
`#ff006e` / `#8338ec` / `#ffbe0b` / `#3a86ff` / `#06d6a0`。它的警告也很明确：
**"No large gray areas"** —— 大面积灰会立刻杀死这个风格。

但对课程表这种高密度网格，直接搬多巴胺风是灾难：8 个高饱和色块铺满一屏，眼睛没有落点。
「文具盒」的策略是**取能量不取饱和度**：色相拉满、明度压平。

### 1.5 Editorial / Swiss 作为对照面

参考 [stylekit · Editorial](https://www.stylekit.top/en/styles/editorial) 与
[Swiss International](https://www.stylekit.top/en/styles/swiss-style)：衬线标题 + 无衬线正文、
严格网格、去装饰。这两派是「素墨」的骨架，但要避开的坑也在这：Editorial 的规则是
「不要彩色强调」，而课程表**必须**有课程色。素墨的解法是把课程色压成低饱和的「淡墨」层级。

### 1.6 一句话结论

> 2025-2026 的界面不再比「干净」，比的是**有没有一个能被记住的动作**。

## 3. 素墨（清爽极简 · 重构）

### 3.1 主张

> **留白是内容，朱砂是标记。**
> 极简不是「少了什么」，是「剩下的每一笔都有依据」。

旧版把「极简」理解成了「没有」——白底、系统蓝、大圆角，凑在一起是 iOS 设置页，不是课表。
素墨换成另一个方向：**墨与纸的关系**。纸是冷的近白，墨是近黑，中间全部留给留白；
整套界面只允许一个高饱和——朱砂，只出现在「今天」和「当前节次」上。

于是「极简」从一个形容词变成了规则：**任何不是今天的东西，都不许有颜色。**

### 3.2 隐喻

一张宣纸上的课表。课程是一笔笔淡墨（低饱和、低明度差），今天是一枚按下去的朱印。

- 墨迹有浓淡：课程色不靠色相区分，靠**饱和度与明度的细微差**区分；
- 朱印只有一枚：强调色在 2 屏内可见 ≤ 3 处；
- 纸是冷的：底色不用米黄（那是纸本暖白的领地），用 `#FBFBFC`。

### 3.3 禁区

1. **不用任何蓝色系强调色。** 蓝是动态取色与液态玻璃的语言，素墨一旦出现蓝就立刻被同化。
2. **不用阴影、模糊、渐变。** 分层只靠留白宽度与 hairline。
3. **课块不用高饱和色。** 卡面彩度砍到 55%，全部是「淡墨」；谁最亮谁就是焦点——焦点只能给今天。

### 3.4 Token

| text | #17181A | 正文（墨） |

| border | #E3E5E9 | hairline |
| accent | #C0412C | 朱砂（仅今日/当前） |
| onAccent | #FFFFFF | 朱砂上的字 |

| surfaceVariant | #24272B |
| text | #EDEEF0 |

课板 8 色（淡墨，明度压平、饱和度 25-40%）：

```

#2F5F6B  #6E6A3A  #56667A  #5A5F66
```

### 3.5 组件形态

- **课块**：淡墨卡面 + 1dp 同色系描边（`tone.line`），圆角 10dp。课程名用 `tone.ink` 而非课程原色。
- **时间轴首列**：宽 44dp，刻度用 `textMuted` + 衬线数字，节次编号 10sp，只标 1/3/5，其余留白。
  **故意不全标**——留白是设计的一部分。
- **今日高亮**：不用填充色块。今日列顶部一枚 6dp 朱砂圆点 + 今日课块描边提到 `accent` 的 30% 透明度。
  全屏只有一个朱砂点。
- **周切换**：无胶囊、无底。一行字，当前周 SemiBold + 下方 16dp 的 1.5dp 朱砂短线。
- **空状态**：一行衬线大字 + 两行说明。不给插画、不给色块。
- **底部导航**：沿用现有浮岛，但投影压到最轻、不使用 pill 高亮，选中项用实心图标 + 朱砂 3dp 圆点。

### 3.6 动效

- 曲线：`spring(dampingRatio = 1.0f, stiffness = 480f)` —— 临界阻尼，无回弹，落地即停。
- 等效时长 160-200ms。周切换横向位移 24dp；课块入场 120ms 淡入 + 4dp 上移。
- **不做**：缩放、弹性、旋转。「墨不会跳。」

### 3.7 布局语言

绑定**编辑式网格**（上午 / 下午 / 晚上三段标题 + 段内一条 hairline）。

- 8pt 基准；页边距 20dp（三套里最宽）；
- 课块间距 4dp，时段分段间距 28dp——分组比块更明显；
- 行高 1.9x，正文 13sp / 时间刻度 11sp / 段标题 12sp + 字距 0.08em；
- 宁可少显示一节课，也不挤压。

## 4. 灯下（墨夜纯黑 · 重构）

### 4.1 主张

> **纯黑不是没有光，是只有一盏灯。**
> 层级不靠阴影，靠「灯照到哪儿」。

旧版是「纯黑 + 蓝 + 高对比」，一个任何 App 都能开的暗色模式。而纯黑最有意思的地方
恰恰不是黑，是**光的稀缺性**：既然纯黑上投不出阴影，就别假装有层，改用「照明」组织注意力。

规则只有一条：**只有一处亮，其余沉下去。**

### 4.2 隐喻

熄灯后的书桌。台灯照出的那一块是今天的课，光斑边缘以外全部沉在暗处。
琥珀色的灯泡是唯一光源，其余全部是黑的灰阶。

### 4.3 禁区

1. **不用 `#FFFFFF` 作正文。** 纯白在纯黑上会 halation。正文用暖白 `#E8E3D9`。
2. **不用阴影 / 发光模糊做层级。** 纯黑上阴影失效；发光模糊会把「唯一的灯」稀释成霓虹。
3. **不做霓虹夜店风。** 光源只有一个，课程色只能是「被这盏灯照到的物体」，不能自己发光。

### 4.4 Token

暗色（主题本体）：

| token | hex | 说明 |
|---|---|---|
| bg | #000000 | 真黑，AMOLED 像素关闭 |
| surface | #0A0A0B | 一级面板（窄灰阶，仅够分层） |
| surfaceVariant | #121214 | 今日列 / 选中态 |
| text | #E8E3D9 | 暖白正文（非 #FFFFFF） |
| textMuted | #9B9384 | 带一点点暖的灰 |
| border | #26262A | **承担全部层级的 hairline** |
| accent | #F2A93B | 琥珀灯光 |
| onAccent | #1A1206 | 琥珀上的深墨字 |

亮色（「白天版灯下」，非主角但需可用）：

| token | hex |
|---|---|

| surface | #FFFFFF |
| surfaceVariant | #EFEEE9 |
| text | #1A1815 |
| textMuted | #655F57 |
| border | #E2E0D9 |

| onAccent | #FFFFFF |

```

#4E9DB3  #A98BC4  #C9718A  #8C9199
```

```
暗: #2b1700 #301202 #181f00 #002317 #00202a #23142f #300f19 #191c20
```

参数：`toneBias(lightL 0.960, lightChroma 1.0, darkL 0.225, darkChroma 1.25)`；`radius 6/12/16`；`serifTitle = false`。

**暗色卡面明度压到 0.225、彩度拉到 125%**：卡面几乎沉进纯黑，但彩度反过来拉高——
这正是「被一盏暖灯照到」的物理直觉：环境越暗，被照到的物体看起来越暖、越饱和。

### 4.5 组件形态

- **课块**：圆角 6dp（三套最方——「仪器感」，对应台灯的金属臂）。卡面 1dp `tone.line` 描边。
- **时间轴首列**：40dp，等宽数字（tabular figures），刻度 `textMuted`，当前节次用琥珀 1.5dp 左缘线。
  **时间列是全 app 最理性的地方**，数字必须对齐。
- **今日高亮**：整列背景提到 `surfaceVariant #121214`（「灯照到这一列」），列左缘一条 2dp 琥珀线。
  暗色下这条琥珀线是全屏最亮的元素。
- **周切换**：底 `surface`，文字；当前周用琥珀色小字 + 无容器。切周时列表横移，灯不动。
- **空状态**：暖白大号一句「这周还没有课」，下方灰刻度。
- **底部导航**：`surface #0A0A0B` + 顶部 `border` hairline；选中图标琥珀，未选中 `textMuted`。
  **不用 pill 高亮块**（纯黑上 pill 会像一块污渍）。

### 4.6 动效

- 曲线：`spring(dampingRatio = 0.85f, stiffness = 380f)` —— 轻微过冲，像灯臂被碰了一下。
- 等效 260-320ms。暗色页面转场 300ms 交叉淡入，**不做位移**（纯黑 + 位移会放大 black smearing）。
- 滚动：避免纯黑上大幅位移的视差。

### 4.7 布局语言

绑定**色块制网格**（无色线，靠底纹与色块自身上下分层）。

- 8pt 基准；页边距 12dp（三套最窄，夜间信息密度优先）；
- 课块间距 3dp，几乎贴合成一整块「光斑」；
- 正文 12sp，时间刻度 10sp 等宽；
- 段与段之间不用标题，只用 `surfaceVariant` 的一段背景带暗示分界。

### 4.8 已知风险

- `accent #A85F12` 在亮色底 `#F6F6F4` 上是 **4.50**，刚好压线。**只用于大字号 / 图标**，正文强调一律用 `text`。
- 纯黑 + 快速滚动存在 black smearing，已通过「暗色转场不用位移」规避一部分；列表滚动本身无法完全消除。
- 课程色对 `#000000` 的最低分离度为 6.21，暗色卡面即使沉到 0.010 亮度仍清晰可辨。

## 5. 文具盒（多彩活泼 · 重构）

### 5.1 主张

> **颜色是有编号的，不是撒出来的。**
> 多彩的前提是秩序；没有秩序的多彩，读起来就是噪音。

旧版「高饱和糖果色」的问题不是颜色不好看，是**没有排序规则**：8 个色随便用，两节课挨着，
谁都抢不到注意力，整块网格变成一锅粥，而且和动态取色（同样是多色）没有区分。

规则很硬：**色相均分、明度归一、数量封顶 8，顺序不可变。**

### 5.2 隐喻

开学第一天拆开一盒新文具：珠光笔、荧光笔、便利贴、彩色圆珠笔。每节课是一张便利贴，
被贴在奶油色的课表纸上。

### 5.3 禁区

1. **不用纯 `#FFFFFF` 作底。** 冷白 + 高饱和 = 廉价电商感。底必须是奶油纸白 `#FFFCF4`。
2. **不超过 8 个课程色，不运行时随机派生。** 第 9 门课回到第 1 色。颜色是「编号」，不是「随机数」。
3. **不做渐变彩虹背景、多色阴影、彩色光晕。** 能量全部放在课块本身，容器越朴素越好。

### 5.4 Token

亮色：

| token | hex | 说明 |
|---|---|---|
| bg | #FFFCF4 | 奶油纸白（暖，非 #FFFFFF） |
| surface | #FFFFFF | 浮起面板 |
| surfaceVariant | #FFF1C9 | 高亮纸胶带黄 |
| text | #241E1A | 近黑（带一点点暖） |
| textMuted | #6F6355 | 暖灰 |
| border | #EFE2C8 | 纸的裁切线 |
| accent | #CE3B26 | 橡皮红（白字 4.91） |
| onAccent | #FFFFFF | |

暗色：

| token | hex |
|---|---|
| bg | #17141A |
| surface | #211D26 |
| surfaceVariant | #332B3D |
| text | #F5F0E8 |
| textMuted | #B0A6BC |
| border | #3A3342 |
| accent | #FF8A6B |
| onAccent | #2A0F06 |

课板 8 色（色相均分、明度归一到 L*≈55-62，任意两色并排都不打架）：

```
#C98A00  #F26A2E  #E8465C  #E85C90
#7C5CFF  #2F8FEF  #22B37D  #14A8A2
```

> 这 8 色全部压掉了原色的荧光感（比 Dopamine 的 #ff006e / #ffbe0b 更沉），
> 因为它们要在奶油底上大面积平铺，不是做 CTA。

渲染后实际卡面：

```
亮: #fcecd6 #feeae2 #ffe8e8 #fee8ee #edecff #e5f0fd #dcf6e8 #d6f6f3
暗: #3e2904 #462315 #472123 #45202c #2c294a #162f4a #0a3725 #023633
```

参数：`toneBias(lightL 0.950, lightChroma 1.20, darkL 0.300, darkChroma 1.30)`；`radius 14/18/24`；`serifTitle = false`。

**彩度拉到 120% / 130%** 是本主题的核心：卡面是 8 张不同色相的便利贴，不是 8 块同一个浅灰。

### 5.5 组件形态

- **课块**：圆角 14dp + 1dp 同色描边；彩度是主角，卡面比其他两套明显更「有色」。
- **时间轴首列**：36dp（最窄），刻度旁加一个小色点对应「当前节的课程色」，让时间轴也参与配色。
- **今日高亮**：今日列底 `surfaceVariant #FFF1C9`（纸胶带），顶部压一条 3dp 的周几色。
  **周几有颜色**是这个主题独有的一条。
- **周切换**：彩色标签页——当前周是一个圆角 `surface` 标签，其下压 3dp 色条，颜色随周数在 8 色里循环。
- **空状态**：用纯色几何画一个开口的文具盒剪影（不用位图），文案「这周还是空盒子」。
- **底部导航**：`surface` + 顶部 hairline；选中项是一个小圆角块（`surfaceVariant`）+ 图标取当前周色。
  **允许一个 pill，因为它就是这个主题的语法。**

### 5.6 动效

- 曲线：`spring(dampingRatio = 0.55f, stiffness = 620f)` —— 明显回弹，「便利贴被贴上去」的手感。
- 等效 180-220ms，但因为有回弹感知更长。课块入场 scale 0.92 → 1.0 + 40ms 错峰
  （一行 7 个块依次弹入，总时长不超过 340ms）。
- **克制点**：同屏同时运动的元素 ≤ 7 个；不做循环呼吸动画。

### 5.7 布局语言

绑定**色块制网格**（颜色够多了，线只会更乱）。

- 4pt 基准（三套里唯一用 4pt，更「手作」）；页边距 16dp；
- 课块间距 6dp，块之间留缝让每个「便利贴」独立成立；
- 标题重字重（Bold/ExtraBold），正文 13sp。

## 6. 实现：`CourseToneBias`

### 6.1 改动

`core/theme/ThemePreset.kt` 新增：

```kotlin
data class CourseToneBias(
    val lightL: Float = 0.945f,      // 亮色卡面明度（OKLCH L）
    val lightChroma: Float = 1f,     // 亮色卡面彩度系数
    val darkL: Float = 0.285f,       // 暗色卡面明度
    val darkChroma: Float = 1f,      // 暗色卡面彩度系数
) { companion object { val Default = CourseToneBias() } }

data class ThemePreset(
    /* …原字段… */
    val toneBias: CourseToneBias = CourseToneBias.Default,
)
```

`core/theme/Tone.kt` 的 `courseTone` 增加参数：

```kotlin
fun courseTone(
    source: Color,
    isDark: Boolean,
    bias: CourseToneBias = CourseToneBias.Default,
): CourseTone
```

只改了 **container 与 line 的明度/彩度**：

```kotlin
// 亮色
container = tonal(bias.lightL,       0.028f * scale * bias.lightChroma, hue)
line      = tonal(0.855f,            0.060f * scale * bias.lightChroma, hue)
// 暗色
container = tonal(bias.darkL,        0.045f * scale * bias.darkChroma, hue)
line      = tonal(0.400f,            0.060f * scale * bias.darkChroma, hue)
```

`ink / inkMuted / highlight / shade` **不参与偏置**——它们由 container 与正文门槛反解，
一起动会破掉 `CourseToneTest` 钉住的 AAA / AA 保证。

### 6.2 为什么默认值是安全的

`CourseToneBias.Default` 的四个数就是改版前的硬编码常量（0.945 / 1.0 / 0.285 / 1.0），
所以**不传参数 = 逐位一致的旧行为**。纸本暖白、动态取色、液态玻璃三套主题的渲染结果
一个像素都没变（`CourseToneBiasTest` 的 `默认偏置与改版前的硬编码行为完全一致` 用例钉住这一点）。

### 6.3 调用点

| 文件 | 改动 |
|---|---|
| `CourseBlock.kt` | `courseTone(color, isDark, preset.toneBias)` |
| `TodayCourseRow.kt` | 从 `LocalCoursePreset` 取 `toneBias` |
| `TodayClassCards.kt` ×2 | 同上 |
| `CourseDetailSheet.kt` | 同上 |
| `NowMarker.kt` | 未改（用 accent 色派生，与课程身份无关） |

3. 三套的动效曲线两两不同 —— 1.0/480、0.85/380、0.55/620。
