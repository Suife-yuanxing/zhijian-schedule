## 1. 三套主题各自的验收点

### 素墨（清爽极简）

| 看什么 | 合格标准 |
|---|---|
| 页面底色 | 冷近白 `#FBFBFC`，**不是纯白**、也不是米黄 |
| 强调色 | 只有朱砂 `#C0412C`；全屏扫一遍，蓝色一处都不该有 |
| 课块 | 淡到几乎融进纸里，靠 1dp 描边分界；圆角 10dp |
| 排版 | 「本周课表」是**衬线**字体 |
| 今日 | 今日列有一枚朱砂小点 / 描边提到朱砂色 |
| 对比度 | 户外强光下课程名仍读得清（这是旧版最大的问题） |
| 空状态 | 「周五下午，空着。让它空着。」一行衬线大字 |

**最容易翻车的点**：素墨课块彩度砍到 55%，如果八门课在小屏上难以区分，说明裁过头了，要回滚 `lightChroma`。

### 灯下（墨夜纯黑）

| 看什么 | 合格标准 |
|---|---|
| 底色 | 真黑 `#000000`，OLED 上该区域的像素应完全熄灭 |
| 正文色 | 暖白 `#E8E3D9`，**不是刺眼的纯白** |
| 强调色 | 琥珀 `#F2A93B`，全屏最亮的元素是今日列那条琥珀左缘线 |
| 课块 | 沉得几乎看不见，但色相仍能分辨；圆角 6dp（最方） |
| 层级 | 全靠 hairline 描边分层，**没有阴影**（纯黑上本来就投不出） |
| 滚动 | 快速上下滑课表，看有没有黑色拖影（black smearing） |
| 分散光 | 散光/夜里关灯看，白字不应发晕（halation） |

**最容易翻车的点**：
1. 灯下亮色主题里 `accent #A85F12` 只有 4.50 对比度，**压线**——如果那个场景有正文级强调文字用了它，会读不清。
2. 暗色课块明度压到 0.225，如果某门课（尤其深蓝/深绿）在小屏上几乎看不见，说明压过头。

### 文具盒（多彩活泼）

| 看什么 | 合格标准 |
|---|---|
| 底色 | 奶油纸白 `#FFFCF4`，**不是纯白**（纯白 + 高饱和 = 廉价电商感） |
| 课块 | 明显比另外两套"有色"——八张不同色相的便利贴 |
| 八色 | 八门颜色并排，任意两者都不该撞；都不该刺眼 |
| 强调色 | 橡皮红 `#CE3B26` |
| 今日列 | 底是纸胶带黄 `#FFF1C9` |
| 圆角 | 14dp（三套最圆） |
| 标题 | 重字重（Bold 级） |

**最容易翻车的点**：彩度拉到 120%，八色同屏饱和度叠加，可能"跳得眼睛疼"。若如此，优先降 `darkChroma`（暗色 130% 更容易过），再考虑亮色。

## 2. 三套一起要验的（重构的核心目标）

这是本次改动的**真正重点**，单独列出来：

### 2.1 主题终于能改课块了

改版前 `courseTone` 只吃源色与明暗，跟主题无关——同一门课在六套主题里渲染出**完全一样**的课块。
本次新增 `CourseToneBias`。验收动作：

1. 选一门颜色显眼的课（比如蓝色）；
2. 依次切「素墨 → 灯下 → 文具盒」；
3. **观察这门课的课块**：应该是「淡墨 → 沉稳暖调 → 鲜亮便利贴」三种明显不同的观感。

如果切主题时课块**纹丝不动**、只有页面底色在变，说明偏置没接上，是回滚级别的问题。

### 2.2 没改的三套必须零变化

切「纸本暖白」「动态取色」「液态玻璃」——**应和改版前完全一模一样**，一个像素都不该变。
`CourseToneBias.Default` 就是改版前的常量，这是回归护栏。

### 2.3 网格语言

每套主题都要试「编辑式 / 色块制」两种网格（设置里），确认：
- 编辑式：上午/下午/晚上分段 + 段内 hairline
- 色块制：没有网格线，靠底纹与色块分层
- 两种都不该出现课块重叠、错位

| 风险 | 说明 |
|---|---|
| 灯下亮色 accent 4.50 压线 | 只用于大字号/图标；正文强调应走 `text` |
